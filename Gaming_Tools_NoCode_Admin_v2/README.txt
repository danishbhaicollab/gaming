GAMING TOOLS — NO-CODE ADMIN EDITION
=====================================

Files:
- index.html       Main website
- admin.html       No-code Admin Panel
- data.js          Website content/data
- app.js           Website behavior
- style.css        Design

NO-CODE WORKFLOW
----------------
1. Open admin.html in your browser.
2. Change Website Settings, Knowledge Sections, Articles and Quick Tools.
3. Click Save.
4. Click "data.js Download".
5. In GitHub, replace the old data.js with the downloaded data.js.
6. Netlify will automatically deploy the new version if your GitHub repository is connected.

IMPORTANT
---------
The Admin Panel itself stores edits in your browser. The downloaded data.js is the file that makes your changes part of the live website after you replace it in GitHub.

For a true cloud CMS where changes are saved online instantly without uploading data.js to GitHub, connect a proper backend/database later (for example Supabase or another secure CMS).

SECURITY
--------
This static Admin Panel does not provide secure server-side authentication. Do not put passwords, API keys, payment secrets, or private information in it.
